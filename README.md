# kdonusum — Urban Transformation Requirements / Kentsel Dönüşüm Gereksinimleri

User requirement specifications for a system that manages **risky buildings** (*riskli yapı*), **risky zones** (*riskli alan*) and **reserve building areas** (*rezerv yapı alanı*) under Turkish Law No. 6306 on the Transformation of Areas Under Disaster Risk.

The requirements are derived from the *6306 Sayılı Kanunun Uygulama Yönetmeliği* (RG 15/12/2012-28498, consolidated up to RG 4/2/2026-33158). Every requirement is traced to its article and paragraph.

## Documents

Both documents cover the same scope: actors, Mermaid sequence diagrams of the main workflows (risky-building determination → objection → demolition, risky zone / reserve area designation, majority decision and auction), functional and non-functional requirements, deadlines, a case state model, open legal issues and a traceability matrix.

Diagrams are written in [Mermaid](https://mermaid.js.org/) and render on GitHub and in the VS Code Markdown preview.

## Türkçe özet

Bu depo, 6306 sayılı Kanun kapsamında riskli yapı tespiti, itiraz, tahliye ve yıkım ile riskli alan ve rezerv yapı alanı belirlenmesi süreçlerini yönetecek bir sistemin kullanıcı gereksinimlerini içerir. Gereksinimler Uygulama Yönetmeliğinin ilgili maddelerine bağlanmıştır.
